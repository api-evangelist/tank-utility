# Tank Utility

> Tank Utility provides LTE-connected propane tank monitors and a read-only REST API that returns fuel-level and telemetry data (tank fill %, temperature, battery, last-report time) for the monitors on an account. Access is via a short-lived token exchanged from account credentials. Tank Utility is owned by Anova.

This llms.txt was generated by API Evangelist from apis.yml and the repo artifacts; Tank Utility does not publish its own /llms.txt.

## API

- [Tank Utility Propane Monitor API (OpenAPI)](https://raw.githubusercontent.com/api-evangelist/tank-utility/refs/heads/main/openapi/tank-utility-devices-openapi.yml): Reconstructed OpenAPI 3.0 for the three read-only operations — getToken, getDevices, getDevice. Base URL https://data.tankutility.com/api.

## Authentication

- Get a token: HTTP Basic (account email + password) against `GET /api/getToken`; the token is valid ~24 hours.
- Read calls: pass the token as the `token` query parameter to `GET /api/devices` and `GET /api/devices/{deviceId}`.
- [Authentication profile](https://raw.githubusercontent.com/api-evangelist/tank-utility/refs/heads/main/authentication/tank-utility-authentication.yml)
